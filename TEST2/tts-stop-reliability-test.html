TTS Stop-Reliability Test Harness

Isolated test page — no MediaPipe, no webcam, no dependency on the real app. Tests three things against real speechSynthesis in this browser:
1) whether polling the speaking property catches a stop faster/more reliably than waiting on onend,
2) whether short (single-sentence) chunking + iframe recycling reduces overrun compared to a plain long utterance,
3) whether a busy-loop standing in for MediaPipe's per-frame CPU cost changes either result.
