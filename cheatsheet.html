Your Own Insights (In Your Words)

🔢 Arrangement Inside Arrangement

"it is basically arrangement inside arrangement"
  • Multiple separate groups picking independently
  • Each group arranges within itself first
  • Then combine → MULTIPLY
  • Example: ³P₃ × ³P₂ × ³P₁ = 6 × 6 × 3 = 108

🚫 Canceling Arrangement Inside Arrangement

"canceling arrangement inside arrangement"
  • Groups are indistinguishable from each other
  • Swapping groups creates duplicates
  • Remove duplicates → DIVIDE by groups!
  • Example: Split 10 into 5 groups → ÷ 5!

🃏 C is Just Arranging Identical Objects

"C is just there because coincidentally formulas somehow make up"
  • Choosing 2 positions = arranging identical bars
  • 7! ÷ 5! ÷ 2! = ⁷C₂ — same thing!
  • C = shortcut for identical object arrangements
  • Stars & Bars uses C for this exact reason

💉 Bayes = Simultaneous Equations

"oh its just simultaneous equations"
  • Pr[B|A] = Pr[A∩B] / Pr[A] → equation 1
  • Pr[A|B] = Pr[A∩B] / Pr[B] → equation 2
  • Both share Pr[A∩B] → solve and substitute!
  • GIVEN = what you SEE, FIND = hidden cause

🔄 With/Without Replacement = Dependent/Independent

"my part matters when replaced, ur part matters when not replaced"
  • With replacement → pool doesn't change → Independent → Pr[A] × Pr[B]
  • Without replacement → pool shrinks → Dependent → Pr[A] × Pr[B|A]

∞ Real Numbers = Zoom In Forever

"zoom out infinitely and new numbers keep emerging"
  • Integers: infinite in ONE direction only
  • Real numbers: infinite in EVERY direction
  • Can always zoom in and find new numbers
  • That's why reals are Uncountable!

Key Formulas With Intuition

Combinations

C vs P — The Golden Rule

"P needs ÷ r! to fix it. C is already done — ready to use as is!"
Permutation (order matters)
ⁿPᵣ = n! / (n-r)!
Combination (order doesn't matter)
ⁿCᵣ = ⁿPᵣ / r!
Never do ⁿCᵣ ÷ r! — the r! is already inside C!
Polygon Diagonals

Diagonals in n-sided Polygon

"All possible lines between vertices, minus the sides themselves"
ⁿC₂ − n
= n(n-1)/2 − n
ⁿC₂ = all lines between any 2 vertices
−n = remove the n sides (not diagonals!)
Pascal's Identity

Pascal's Identity

"Alice is either IN or OUT — no in-between. Add both cases!"
C(n+1,k) = C(n,k) + C(n,k-1)
Alice OUT → pick k from remaining n → C(n,k)
Alice IN → pick k-1 from remaining n → C(n,k-1)
No overlap → just ADD!
Inclusion-Exclusion

Inclusion-Exclusion

"20 like cricket, 15 like football, 8 like both — subtract the overlap!"
Two sets
|A∪B| = |A|+|B|−|A∩B|
Three sets
|A∪B∪C| = |A|+|B|+|C| −|A∩B|−|A∩C|−|B∩C| +|A∩B∩C|
Add all → subtract pairwise → add the middle back once!

Probability Rules

Inclusion-Exclusion

Pr[A∪B] = Pr[A]+Pr[B]−Pr[A∩B]
A OR B happening. Subtract overlap because it got counted twice!

Product Rule

Pr[A∩B] = Pr[A] × Pr[B|A]
A AND B both happening. Use Pr[B] only if independent (with replacement)!

Total Probability

Pr[B] = Pr[A]×Pr[B|A] + Pr[Ā]×Pr[B|Ā]
Don't know Pr[B]? Split into ALL scenarios and add them up!

Bayes' Rule — Flipping The Probability

"You SEE something (evidence) → you figure out the hidden CAUSE" — just two simultaneous equations sharing Pr[A∩B]!
YOU KNOW
Pr[B|A]
→
YOU WANT
Pr[A|B]
→
BAYES GIVES YOU
Pr[A] × Pr[B|A] / Pr[B]
THE FORMULA
Pr[A|B] = Pr[A] × Pr[B|A] / Pr[B]
Top = Pr[A∩B] = sick AND positive
Bottom = Pr[B] = everyone who tested positive (use Total Probability!)
MLE vs MAP
MLE = which cause fits evidence BEST (ignores rarity)

MAP = which cause is most likely after considering rarity

MAP = MLE + common sense!

Infinity & Countability

A set is Countable if you can make a numbered list of all its elements. A set is Uncountable if no list can ever capture all of it.

✅ Countable (same size as ℕ)

  • Natural Numbers ℕ = {0,1,2,3...}
  • Integers ℤ — list: 0,1,-1,2,-2,3,-3...
  • Fractions ℚ — zig-zag through the grid!
  • Pairs of Natural Numbers (ℕ×ℕ)
  • All Finite Strings

❌ Uncountable (bigger than ℕ)

  • Real Numbers ℝ — zoom in forever, new numbers always appear!
  • Interval (0,1)
  • Power Set of ℕ
  • Cantor's Proof: always build a number that differs from every entry on the diagonal!
