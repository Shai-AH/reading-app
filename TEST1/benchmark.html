Phase 13.5 — Concurrent-Load Benchmark

Standalone test harness. Does not touch main.js / index.html. Measures MediaPipe FaceLandmarker frame timing alone, then with Kokoro TTS WASM inference running concurrently, on this device.

1. Setup

First run downloads the Kokoro model (tens–hundreds of MB depending on precision) — cached by the browser after. Run via python3 serve.py in this folder (not npx serve — it sets the COOP/COEP headers WASM threading needs) and open http://localhost:8000/benchmark.html. Opening the file directly (file://) won't work — ES module imports need CORS. Kokoro runs in a Worker (kokoro-worker.js), off the main thread, so its compute can't block the MediaPipe loop being measured.
