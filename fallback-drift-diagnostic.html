Fallback-Advance Drift Diagnostic

This measures how far behind the real TTS audio the fallback-advance highlighter falls, using the exact estimateWordDuration / estimateFallbackDelayMs logic from js/cadence.js. It does NOT touch main.js or the real app — this is a standalone page. Place this file in the same folder as main.js (so ./js/cadence.js resolves) and deploy it alongside the app, or serve it locally.

How to run it: tap Start, then put the phone where you can hear it clearly. The instant you HEAR each new word spoken, tap the big blue button below (or press Spacebar). Don't try to read the highlighted word — go purely by what you hear, one tap per word, as fast and accurate as you can manage. This is your ground truth; the fallback logic runs independently in the background.
